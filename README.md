## Getting Started

### 1. Clone the repository
```sh
git clone https://github.com/Ayman2329/SCT_ML_1.git
cd SCT_ML_1
```

### 2. Install requirements
```sh
pip install -r requirements.txt
```

### 3. Train the model
```sh
python src/train.py --config configs/train_config.yaml
```

### 4. Evaluate or predict
```sh
python src/evaluate.py --model-path models/latest_model.joblib
```
